# وثيقة الأمان، لوحات الإدارة، والمزامنة لمتجر نجوم دلتا (Delta Stars v5.3.6)

تحدد هذه الوثيقة بصدق تقني واحتراف كامل تفاصيل الأمان، صلاحيات الدخول، المصادقة البيومترية، سياسة الخصوصية، وآليات مزامنة التحديثات.

## 1. بيانات الدخول الأولية (Bootstrap Credentials)

تدار صلاحيات "الإدارة السيادية" (Sovereign Admin) و"قسم المطور" (Developer Panel) عبر متغيرات البيئة السرية ومفاتيح الـ Bootstrap المضمنة في الخادم والواجهة:

- **الإدارة السيادية (Admin):** يُستخدم البريد الإداري الأساسي أو اسم المستخدم المشفر مع كلمة المرور الأولية (Bootstrap Password) المعرفة في `VITE_ADMIN_BOOTSTRAP_PASSWORD`. عند الدخول الأول، يتم توجيه المشرف لتغيير كلمة المرور فوراً عبر واجهة الأمان.
- **قسم المطور (Developer):** يُستخدم بريد أو حساب المطور مع كلمة المرور الأولية المعرفة في `VITE_DEV_BOOTSTRAP_PASSWORD`. يمنح هذا القسم صلاحيات الجذر (Root Access) لإدارة قاعدة البيانات، الكتالوج، الفروع، والمزامنة.

*ملاحظة أمنية:* لا يتم تخزين كلمات المرور الصريحة في قاعدة البيانات، بل تشفر وتتحقق عبر الخادم. ويمكن تعديل أو إعادة تعيين هذه الأسرار في أي وقت من قسم الأسرار (Secrets) في لوحة إدارة المشروع أو متغيرات البيئة في مستودع GitHub.

## 2. المصادقة البيومترية (البصمة والتعرف على الوجه)

يدعم النظام التحقق الحيوي عبر قدرات الجهاز (Biometric Authentication):
- يعتمد النظام على موازاة واجهات WebAuthn والمصادقة المحلية المدعومة في المتصفحات وتطبيقات WebView للهواتف.
- يتم تسجيل وتوثيق المفتاح الحيوي للمستخدم في جلسة آمنة عند تفعيل الميزة من الملف الشخصي أو لوحة التحكم.

## 3. سياسة الخصوصية ورابطها الرسمي

تم اعتماد وثيقة سياسة الخصوصية الرسمية لشركة نجوم دلتا للتجارة، والمتوافقة تماماً مع سياسات متجر Google Play وApple App Store:
- **ملف الوصول المباشر:** متاحة في ملف `client/public/privacy-policy.html` وكذلك عبر مسار الويب العام في التطبيق (`/legal/privacy`).
- **نطاق الحماية:** تغطي جمع بيانات العملاء (الاسم، رقم الهاتف، عنوان التوصيل)، حمايتها ببروتوكولات التشفير القياسية، وعدم مشاركتها مع أي أطراف ثالثة إلا لأغراض الشحن والتوصيل الرسمية.

## 4. المزامنة والتحديثات التلقائية

يتكامل النظام مع خطوط البناء التلقائي عبر GitHub Actions:
- أي تحديث يتم دفعه إلى مستودع المشروع `deltastars-com/D.S1` يُفعّل آلياً عمليات الفحص، اختبارات الوحدات (Vitest)، تجميع تطبيق الويب، وبناء نسخ تطبيق الهواتف (Android APK وiOS IPA).
- يتزامن متجر الويب المعاينة ونظام الويب التقدمي (PWA) فوراً مع أحدث إصدار منشور في المستودع.
