### حساب رسوم التوصيل:
```typescript
function calculateDeliveryFee(
  branchLat: number, branchLng: number,
  customerLat: number, customerLng: number,
  method: 'normal' | 'express' | 'pickup'
): number {
  const distance = haversineDistance(branchLat, branchLng, customerLat, customerLng);
  
  if (method === 'pickup') return 0;
  if (method === 'express') return Math.max(35, distance * 2.5);
  return Math.max(15, distance * 1.5);
}
```

### حالات الشحن:
```
pending → confirmed → preparing → ready → 
assigned → out_for_delivery → arrived → 
delivered → completed
```
