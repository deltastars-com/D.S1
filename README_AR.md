# 🌟 متجر نجوم دلتا - Delta Stars

> متجر إلكتروني احترافي متكامل مع نظام إدارة شامل وتطبيقات جوالة

## 🎯 المميزات الرئيسية

### 🛍️ واجهة المتجر
- **عرض المنتجات:** تصفح سلس مع تصفية وبحث متقدم
- **سلة التسوق:** إدارة سهلة للمنتجات المختارة
- **الدفع الآمن:** بوابة Moyasar للدفع الإلكتروني
- **التتبع المباشر:** نظام GPS لتتبع الطلبات
- **المساعد الذكي:** عدي (AI Assistant) للإجابة على الأسئلة

## 🚀 البدء السريع

### المتطلبات
- Node.js 18+
- npm أو yarn
- قاعدة بيانات MySQL/TiDB

### التثبيت

```bash
# استنساخ المشروع
git clone https://github.com/your-repo/delta-stars.git
cd delta-stars

# تثبيت المتطلبات
npm install

# إنشاء ملف البيئة
cp .env.example .env

# بدء خادم التطوير
npm run dev
```

### الوصول
- **الويب:** http://localhost:3000
- **الإدارة:** http://localhost:3000/admin
- **المطور:** http://localhost:3000/developer

## 🛠️ الأوامر المتاحة

```bash
# التطوير
npm run dev           # بدء خادم التطوير
npm run build         # بناء الإنتاج
npm run preview       # معاينة الإنتاج

# الاختبار
npm run test          # تشغيل الاختبارات
npm run lint          # فحص الكود

# قاعدة البيانات

npm run db:studio     # فتح Drizzle Studio

# التطبيقات الجوالة
npm run cap sync      # مزامنة Capacitor
npm run cap open      # فتح المشروع الأصلي
```
